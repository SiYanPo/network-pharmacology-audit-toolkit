## 方法学可直接引用的表述

> 对无 OB/DL 数据的化合物（已上市药物、合成单体等），改用可复现的类药性判据：QED ≥ 0.3（Bickerton 2012, Nat Chem Biol 8:849）且 Veber 规则违例 ≤ 1 项（MW ≤ 500、cLogP ≤ 5、HBD ≤ 5、HBA ≤ 10、TPSA ≤ 140 Å²、可旋转键 ≤ 10；Veber 2002, J Med Chem 45:2615）。描述符由 RDKit 从规范 SMILES 计算，逐行数值见 `compounds_kept.csv`，可原样复算。


> 给药途径为 unknown：给药途径未声明：默认按口服处理，但必须在方法学中写明；否则该筛选不可复现。

## ⚠ 特异性警示

达标成分中 **100%** 属于在多数方剂中普遍出现的「泛成分」（槲皮素、山柰酚、木犀草素、β-谷甾醇等）。这类成分不能作为本方的特异性证据。
建议：① 在结果中单列「泛成分」并说明；② 以非泛成分（novel/non-ubiquitous）重跑一次 PPI 与富集作为敏感性分析；③ 讨论中避免用泛成分解释方剂特有功效。

## ⚠ 结构警示（PAINS）

达标成分中有 **1** 个命中 PAINS 警示结构。PAINS 是**实验假阳性**风险提示，不否定其药理活性，但意味着基于比色/荧光读数的体外活性证据需谨慎，并应优先采信非光学读数的实验（SPR、ITC、细胞表型）。
