# CNKI 中文核心检索与导出交接（用户已机构登录）

> 本文件补齐 `references/18-scale-reproduction.md` 引用但此前缺失的检索交接细节。
> 分工：用户在已登录的浏览器里完成「检索 + 导出题录」，把导出文件放到
> `外部数据接入/cnki/`，之后由 skill 用 `np_corpus extract` 同口径解析。

## 为什么需要用户操作

CNKI 的机构登录态绑定在用户浏览器里，WorkBuddy 的浏览器会话无法跨工具调用保持
（历史实测：后台有头浏览器在脚本结束后被回收）。因此采取「用户导出 → skill 接管解析」的分工，
不伪造、不绕过登录。

## 检索式（直接复制）

- 平台：CNKI 中国知网 → 高级检索 https://kns.cnki.net/kns8s/advancedsearch
- 主题：`网络药理学` **AND** `分子对接`（或Su-词：网络药理学 + 分子对接 + 中药）
- 年份：2018–2027
- 来源类别：勾选 **北大核心** + **CSCD**（CSSCI 可选）
- 学科：中药学 / 药学 / 中西医结合（可选，缩小噪声）

## 导出步骤（关键）

1. 勾选命中记录（可全选，或先取前 200 篇做 pilot）。
2. 点「导出/参考文献」→ 选择 **RefWorks** 或 **EndNote** 格式（这两种含题名+作者+年份+摘要，解析最稳）。
   - 不要选「自定义」纯文本；不要只导题名。
3. 下载得到的 `.txt` / `.enw` / `.ris` 文件，原样放到：
   `D:/WorkBuddy/分身文件/2026-11-19-10-40-46/外部数据接入/cnki/`
4. 告诉 skill「CNKI 文件已放好」，skill 执行：
   ```
   python scripts/np_corpus.py extract --dir <外部数据接入/cnki> -o np_out/corpus
   ```
   （中文文本药味识别内置 150+ 药名，与现有 500 篇同口径，可直接并入语料统计。）

## 验收

- 导出的题录条数（skill 会数 RefWorks `RT`/RIS `ER` 记录数）。
- 与现有 PubMed 500 篇的重复率（去重后净新增篇数）。
- 若导出文件含中文摘要，可补做「剂量/阈值披露率」的中文侧复核。

## 已知边界

- 若机构只买到题录不含摘要，则只能做计量分析（年份/期刊/高频药味），不能做阈值抽取。
- 全文下载受版权与机构权限约束，skill 不批量下载全文，只解析用户合法导出的题录。
