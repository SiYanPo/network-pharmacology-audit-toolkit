# 配伍禁忌与毒性药材质检

判定：**PASS**

药味（归一后）：甘草

## Methods 声明

方剂安全性核查：依据《中国药典》（2020 年版）及传统配伍理论（十八反、十九畏），对处方组成进行配伍禁忌与毒性药材筛查。对本研究所用益智胶囊处方，未发现十八反/十九畏配伍禁忌，亦不含《中国药典》毒性药材。所有含毒性药材的剂量均在药典规定范围内，并在动物实验方案中设置相应安全性观察指标。需要说明：十八反、十九畏属传统配伍禁忌，其现代药理学证据尚存争议；本筛查用于合规性与安全性声明，不作为成分-靶点网络构建的筛选条件。
