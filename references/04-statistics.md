# 统计方法：背景、零模型、稳健性与多重校正

> 本章回答一个核心问题：**凭什么说这个结果不是随机产生的？**
> 网络药理学里 80% 的"过度声称"都出在这一步。

## 1. 超几何检验：三个参数，两个最容易错

富集与"成分靶点是否偏向疾病基因"都用超几何：

```
P(X ≥ k) = Σ_{i=k..min(K,n)} C(K,i)·C(N-K,n-i) / C(N,n)
```

| 参数 | 含义 | 常见错误 |
|---|---|---|
| **N** | 背景基因总数 | 用"输入集大小"当 N（致命）；用全转录组（含非编码）当 N |
| **K** | 背景中属于该集合（通路/疾病）的基因数 | K > N（逻辑不可能，说明口径混乱） |
| **n** | 你的基因集大小 | 未剔除不在背景中的基因，导致 n 虚高 |
| **k** | 命中数 | 把"命中"算成"该通路所有基因" |

**必须自检**：`K ≤ N`、`n ≤ N`、`k ≤ min(K,n)`。任一不成立，结果无意义。

### 1.1 背景的选择会改变结论（真实案例）

本平台演示数据（43 个交集基因、135 个疾病基因、25 个成分）：

| 成分 | 靶点数 | 共享 | 背景=全基因组 (N=20596) | 背景=可检出空间 (N=57) |
|---|---|---|---|---|
| Kaempferol | 25 | 20 | 期望 0.16，fold=122，P=2.5e-40 | 期望 18.9，fold=1.06，P=0.35 |

**同一个数据，换背景，从"极度显著"变成"与随机无异"。**

- 全基因组背景回答：*这批靶点是否比随机基因更常落在疾病集里* —— 几乎总是"是"，因为药材靶点本就取自可成药基因。
- 可检出空间背景回答：*在同样会命中这些靶点的基因里，这批是否更集中* —— 这才是机制问题。

**规范做法**：两套都报，主结论用保守的那套，并在方法学写明 `N` 与 `K` 的来源。

#### 1.1.1 真实数据的背景规模敏感性（v1.2.1 新增，非演示数据）

上面是构造数据的例子。在 48 化合物 × 2 型糖尿病的真实数据上（67 交集基因、
KEGG_2021 + Reactome_2022 + GO_BP_2023 三个 Enrichr 库），只改超几何背景 `N`、
固定输入与注释库，做了一次纯参数扫描（结果见工作区 `_research/bg_sensitivity/`）：

| 背景 N | 显著条目数（q<0.05，未折叠） | `Pathways in cancer` 的 P（命中 20/531 不变） | q |
|---|---|---|---|
| 20,596（全基因组默认） | 481 | 2.2e-16 | 1.1e-13 |
| 16,662（注释空间） | 464 | 1.2e-14 | 5.9e-12 |
| 12,000 | 421 | 4.8e-12 | 1.2e-09 |
| 8,000 | 303 | 5.9e-09 | 1.5e-06 |

**读法**：命中数（20/531）一模一样，仅换背景，P 相差约 **2.7 个数量级**、q 相差约 **3 个数量级**，
显著条目从 481 掉到 303。所以：

1. 论文里"背景=全基因组（默认 20596）"与"背景=实际检出基因"给出的显著性强弱**不可直接比较**；
2. **没有实测表达谱时，不得把默认背景下的极小 P 当作强证据**——它有一部分是"背景设得大"带来的；
3. 正确做法：报默认背景的结果，同时明确标注探索性，并在讨论里说明"换用更保守背景会减弱显著性"。

> 复现：`python np_enrich.py -g intersection_genes.txt -m KEGG.gmt,Reactome.gmt,GO_BP.gmt
> --universe N -o out_N/`，N 依次取 20596/16662/12000/8000。脚本对 `--background` 传入实测列表时
> 会做合理性门禁（背景 <2× 输入集直接阻断），因为超几何在小背景上会退化——见 `np_enrich.py`。

## 2. 富集分析的四条纪律

1. **背景可交代**：有表达谱就用"实际检测到的基因"作背景；没有就声明结果为探索性。
2. **多重校正**：BH（FDR）是底线。报告 q 值，并写出校正方法。
3. **命中数下限**：`k ≥ 3`。1–2 个基因的"显著通路"是噪声。
4. **冗余折叠**：GO/KEGG 条目高度重叠。按基因集 Jaccard 聚类，每簇保留最显著代表，
   并**同时报告折叠前后条目数**（如 `54 → 12`）。

> 文献依据：Brief Bioinform 2024（PMID 38436561）用随机表达数据检验主流富集方法，
> 发现多数方法在零假设下 P 值分布偏斜。即：**未校准的 P 值系统性偏乐观**。

## 3. 四套零模型（本平台 `np_null.py`）

| 零模型 | 抽样方式 | 回答的问题 | 判读 |
|---|---|---|---|
| **A 全基因组** | 从 PPI 节点中随机抽同规模基因 | 是否高于随机基因 | 最宽松，几乎必然显著，只作下限 |
| **B 疾病集内** | 从疾病靶点集内随机抽 | 是否高于随机疾病基因 | **机制结论的主要依据**，P<0.05 才可谈"功能模块" |
| **C 度匹配** | 按度分层抽样，匹配度分布 | 是否只是枢纽扎堆 | 不显著 → 紧密性可由度解释，结论必须降级 |
| **D 参照成分库** | 从同类药材库随机取同数量成分 | 交集规模是否超出随机方 | 需 `--ref`；不做则如实标注"未构建" |

**经验 P**：`(1 + #{null ≥ obs}) / (1 + B)`。分子加 1 保证永不为 0；B 至少 1000 才谈 0.001 量级。

### 3.1 为什么 C 组最重要

Brief Bioinform 2021（PMID 33782690）证明：**多数"活性模块识别"算法在度序列相同的随机网络上表现不下降**——
它们主要学到的是节点度。eLife 2024（PMID 39660719）进一步表明 PPI 的幂律度分布本身可由研究偏倚解释。

推论：**"交集基因在 PPI 里连得很紧"这句话，在控制度分布后可能完全消失。**

### 3.1.1 零模型必须自校准（v1.1 新增）

一个零模型只有在**它想控制的东西确实被控制了**时才有效。C 组（度匹配）尤其容易做错：

| 做法 | 抽样 | 结果 |
|---|---|---|
| ❌ 按总体度分布分箱抽样 | 复现总体分布 | 观察集偏高度 → 零模型偏稀疏 → **反保守** |
| ✅ 按观察集度多重集逐一匹配 | 每个观察节点配一个同度节点 | 度分布一致，P 值可解释 |

演示数据的实测差距：

| 零模型 | 零均值（诱导边数） | 观察值 | 表观效应 |
|---|---|---|---|
| v1.0（按总体分箱） | 46.4 | 142 | 3.06× |
| v1.1（精确度匹配） | 119.5 | 142 | **1.19×** |

**效应被高估了约 2.6 倍。** 这不是小数值差异，而是"显著的核心模块"与"仅略高于随机"的区别。

因此脚本会输出校准表（平均 |Δdeg|、精确匹配率、KS 距离），**不达标即判该组结论无效**：

```
| C 组平均 |Δdeg| | 0.00 | 通过 |
| 精确匹配比例   | 1.00 | 通过 |
| KS 距离       | 0.000 | 通过 |
```

> 审计规则 R14 会检查这张表；未通过时不得引用 C 组 P 值。

### 3.2 不要伪造零模型

在"成分-靶点"二分图中，若保持两个边际（每成分靶点数、每靶点成分数）只做边交换，
则大量聚合统计量（覆盖数、共享对数、每成分命中数）**在数学上不变**——检验必然得到 P=1。
这不是"结果稳健"，这是**假检验**。遇到这种情况，正确做法是换统计量或换零模型，而不是报告 P=1。

## 3.5 富集的经验校准（v1.1 新增，可选）

解析 P 值假设"基因可自由置换"，但通路基因存在共表达与共注释，实际零分布常偏离。
`--calibrate N` 做标签置换，输出解析 P 与经验 P 的比值 λ：

```
λ = 中位(解析 P) / 中位(经验 P)
```

- λ ≈ 1：解析 P 可信；
- λ < 1（解析 P 更小）：解析 P 偏乐观，正文应以经验 P 为准；
- λ > 1：解析 P 偏保守（少见）。

报告会同时给出"解析 P<0.05 的条目数"与"经验 P<0.05 的条目数"，两者差距即为需要警惕的部分。

## 4. Hub 稳健性

三个层次，缺一不可：

1. **多指标共识**：度、加权度、介数、谐波接近中心性、PageRank、k-core、聚类系数、MCC。
   各指标转秩后取均值 → `mean_rank`。单用 Degree 会被直接质疑。
2. **边 bootstrap**：有放回重抽边（保持边数），重算 top-k，统计每个基因的**入选频率**。
   - ≥0.90 稳健；0.60–0.90 中等；<0.60 不稳定（不得称 hub）
3. **度校正的桥接残差（v1.1 替代旧的重连检验）**：
   旧做法"度保持重连后比较 top-k 重合率"有两个问题：度序列不变时按度排序的 top-k 恒等（无信息量）；
   而按共识 hub 比较又存在双向解释（高=稳定但只是度；低=特异但不稳）。已废弃。
   现改为 `bc_excess_z`：把介数放到**同度层**（度 ±1）内标准化，回答
   "它是否比同等连接数的节点更像桥"。z>2 提示桥接作用超出度所能解释的范围。

## 5. 效应量：P 之外必须给的东西

| 指标 | 定义 | 用途 |
|---|---|---|
| Fold enrichment | 观察命中 / 期望命中 | 衡量"超出随机多少倍"，比 P 更直观 |
| Rich factor | 命中数 / 该集合大小 | 衡量"覆盖了该通路的多少" |
| 命中基因数 k | 绝对数 | 判断该条目是否由少数基因撑起 |
| 成分覆盖度 / 精确率 | 覆盖疾病基因数 / 该药靶点数 | 反向网络药理学中区分"广撒网"与"精准" |
| 协同增量 | 组合覆盖 − 各自单独覆盖之并 | 量化配伍互补性；为 0 则不得称"协同" |

## 6. 常见统计谬误速查

| 谬误 | 为什么错 | 正确做法 |
|---|---|---|
| 用输入集自身当背景 | N 与 n 相同，期望值被人为抬高 | 用全基因组或实测背景 |
| 只报 p 不报 q | 数百次检验下 p<0.05 必然出现 | BH 校正，报 q |
| 把 P 当效应量 | P 随样本量增大而变小 | 同时报 fold 与 k |
| 富集输入只有一个"核心靶点" | 单基因富集得到的是"该基因参与哪些通路" | 用交集基因集 |
| 用 GSEA 说"通路被激活" | GSEA 只反映表达富集方向 | 需磷酸化/蛋白层面实验 |
| 只报显著不报总数 | 选择性报告 | 报"显著 X / 检验 Y" |
| 零模型迭代 20 次就下结论 | 分辨率不足（最小 P=1/21） | ≥1000 次，或明确说明分辨率 |

## 7. 一段可直接改写的方法学文字

> 靶点集与疾病基因集的重叠采用精确超几何检验，背景取人类蛋白编码基因（N=20,596）；
> 另以"全部预测靶点并集"（N=57）为保守背景重复检验，以避免可成药基因空间带来的富集假象。
> 富集分析采用 Benjamini-Hochberg 校正（q<0.05），并要求命中基因 ≥3；条目按基因集
> Jaccard≥0.5 折叠，折叠前后条目数为 54→12。
> 网络紧密性以 1000 次随机模拟构建零模型：全基因组随机、疾病集内随机、度匹配随机；
> 经验 P 值按 (1+#{null≥obs})/(1+B) 计算。
> Hub 基因以 8 项拓扑指标的秩均值确定，并以 200 次边 bootstrap 估计入选频率（≥0.90 视为稳健）。

## 3.7 多套零模型给出相反结论时怎么办（v1.2）

真实数据里经常出现这种局面（本技能实测）：

| 对照 | 问的问题 | 结果 |
|---|---|---|
| A 全基因组随机 | 比随机基因更紧密？ | P=0.001（显著） |
| B 疾病集内随机 | 比随机**疾病基因**更紧密？ | P=0.26（不显著） |
| C 度匹配随机 | 控制度之后还紧密？ | P=0.006（显著） |

三套对照两个显著一个不显著。此时**不能各说各话**，否则作者一定挑对自己有利的那套。

**统一裁决规则（已内置）**：

1. **B 不显著 → 不得写「核心模块」「紧密互联」**。因为 B 控制了最强的混杂：这些基因本来就是疾病基因，彼此当然互联。
2. **B 显著、C 不显著 → 可写「富集于高连接度疾病基因」，不得写「特异性模块」**。
3. **B、C 均显著 → 可写「超出疾病基因本底的互联模块」，仍属预测层**。
4. **A 单独显著没有任何信息量**。任何疾病相关基因集都比随机基因更互联；只报 A 等于没做对照。

> 优先级 B > C > A 的理由：B 的对照池与观察集共享"疾病基因"这一结构，是最保守的对照；
> C 只匹配度，不匹配疾病属性；A 几乎必然显著。

## 3.8 度分箱为什么不能用「度 ±1」

PPI 的度分布是长尾：281 个节点常散布在 100 多个度值上，度 ±1 的窗口里往往只有 1–2 个同伴。

- 标准差无定义 → `z` 被写成 0 → 报告显示"没有桥接节点"。
- 但真相是**这个度量根本没算出来**，不是"它不特殊"。

正确做法：按度**等频分箱**（每箱 ≥8 个节点），箱内标准化；箱内方差为 0 时输出 `NA`。
本技能实测：改为等频分箱后，CLK1（度=2）的 z=4.6 —— 一个低度但跨模块的桥接节点，
在旧实现下会被完全掩盖。
