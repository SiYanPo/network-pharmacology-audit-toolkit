# 分子对接与分子动力学：判据、几何标准与降级规则

## 1. 现实预期（先看数字）

| 事实 | 数值 | 来源 |
|---|---|---|
| 全 PDB 自动流程 top-1 重对接成功率（RMSD ≤2 Å） | **30.1%** | J Chem Inf Model 2024, PMID 38108627 |
| 经结构质量过滤后的成功率 | **61.8%** | 同上 |
| AlphaFold2 + 对接预测抗菌靶点的平均 auROC | **0.48**（重打分后 0.63） | Mol Syst Biol 2022, PMID 36065847 |
| ML 打分公司（GNINA）优于 Vina 的靶点数 | 89 / 117 | Molecules 2021, PMID 34885952 |

**含义**：
- 对接"跑出结果"和"结果可信"是两件事，中间隔着**重对接验证**。
- 前瞻性基准里，对接预测"哪个化合物作用于哪个靶点"接近随机。
  → 对接**不能**作为靶点正确性的证据，只能作为"该化合物与该靶点结合模式的可能性"。

## 2. 必须报告的 7 项

| 项 | 写法示例 | 不写的后果 |
|---|---|---|
| 受体来源 | RCSB PDB **1TQN**，链 A，分辨率 1.75 Å | 不可复现 |
| 结构处理 | 去水、去共晶配体、加氢（pH 7.4）、Gasteiger 电荷 | 氢键网络不可复现 |
| 口袋定义 | 共晶配体中心（/ 残基 Ser123, Asp189 / 盲对接） | 结果无法比较 |
| 搜索盒 | 22×22×22 Å，中心 (12.3, −4.1, 8.7) | 参数不可复现 |
| 软件与版本 | AutoDock Vina 1.2.5，exhaustiveness=8，seed=42 | 版本差异可达 1 kcal/mol |
| 重对接 RMSD | 1.32 Å（通过 ≤2.0 Å） | 无协议可靠性证明 |
| 阳性对照 | 共晶配体 / 已知抑制剂 | 打分无可比性 |

## 3. 打分判读

| 结合能 | 分级 | 允许表述 |
|---|---|---|
| ≤ −9.0 | 很强 | "预测结合能很低（−9.3 kcal/mol），提示较强结合可能" |
| −9.0 ~ −7.0 | 较强 | "预测结合能较低" |
| −7.0 ~ −5.0 | 弱结合 | "预测可结合，但亲和力有限" |
| > −5.0 | 无结合提示 | 不宜作为候选 |

**红线**：
- 打分 **不是** Kd/IC50，不能写"亲和力为 8.5 kcal/mol"。
- 不同靶点之间的打分**不可横向比较**（口袋大小、埋藏面积不同）。
- 同一靶点内排序才有意义；且需同一协议、同一盒子。

## 4. 相互作用的几何判据（不是能量判据）

| 作用 | 判据 |
|---|---|
| 氢键 | D–H···A 距离 < 3.5 Å，D–H···A 角 > 120° |
| 疏水接触 | 碳-碳距离 < 4.0 Å |
| π-π 堆积 | 环心距 < 5.5 Å（平行）/ < 6.0 Å（T 型） |
| 阳离子-π | 阳离子-环心 < 6.0 Å |
| 盐桥 | 正负电荷中心 < 4.0 Å |

> 这些是**几何**判据。有氢键 ≠ 有亲和力；无氢键 ≠ 不结合。

## 5. 分子动力学（MD）最低配置

| 项 | 常用设置 |
|---|---|
| 力场 | 蛋白 ff14SB / AMBER99SB-ILDN；配体 GAFF2 或 OpenFF Sage |
| 水模型 | TIP3P，盒边 ≥ 1.0 nm |
| 离子 | 0.15 M NaCl，中和电荷 |
| 平衡 | EM → NVT（100 ps）→ NPT（100 ps，重原子位置限制） |
| 生产 | 100 ns（视体系；至少 3 个独立重复更稳） |
| 分析 | 骨架 RMSD、RMSF、Rg、SASA、氢键占有率、MM-PBSA/GBSA |

**判读**：
- 骨架 RMSD 均值 <3.0 Å 且**曲线收敛**（只看均值会掩盖漂移）。
- 配体 RMSD 突然跳升 → 可能解离，需看轨迹。
- MM-GBSA 只作**同靶点不同配体的相对排序**；跨研究比较无意义（单轨迹、通用 GB 参数）。

## 6. 常见失败与处置

| 现象 | 原因 | 处置 |
|---|---|---|
| 打分为正 | 盒子未覆盖口袋 / PDBQT 原子类型缺失 | 检查盒子中心与尺寸；重生成受体 PDBQT |
| 重对接 RMSD >2 Å | 口袋定义偏、质子化错、共晶配体未去除干净 | 回查口袋与受体处理，不要强行解释 |
| 所有配体打分几乎相同 | 盒子过大 / 口袋过浅 | 缩小盒子到配体尺度 |
| MD 轨迹 NaN | 某平台对位置限制力实现缺陷 | 平衡段用 CPU，生产段切 GPU；切换平台重建 integrator |
| 配体参数化失败 | 缺 AM1-BCC（无 AmberTools） | 用 Gasteiger 替代并在方法学声明；或换 OpenFF |
| 结合自由能与实验反相关 | 熵效应、水分子、质子化 | 承认局限；用相对排序而非绝对值 |

## 7. 降级规则（写完先自查）

- [ ] 没有重对接的靶点，结果标"探索性"
- [ ] 重对接失败的靶点，打分不进正文结论
- [ ] 只用对接就写"验证"的句子 → 全部改为"预测"
- [ ] 只对接 top N 成分 → 写明选择依据
- [ ] 未做 MD → 不得写"复合物稳定"
- [ ] 未做实验 → 摘要必须出现 "computationally derived / 计算预测"
