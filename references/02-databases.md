# 数据库与工具速查（含访问要点与替代方案）

> 原则：**每个数据库都写版本 + 访问日期**；每个结果都要能回答"这个数字从哪来"。
> 状态随时间变化，下表"现状"列为 2026-11 的经验值，使用前请以实际访问为准。

## 1. 中药成分与靶点

| 资源 | 内容 | 访问要点 | 坑 / 替代 |
|---|---|---|---|
| **TCMSP** `tcmsp-e.com` | 中药成分 + OB/DL/HL + 靶点 | 免登录；搜索链接带 `token`，会变；需限速 | token 硬编码会失效；并发会封 IP。替代：ETCM、HERB |
| **HERB** `herb.ac.cn` | 高通量实验 + 文献审编，含"药物-靶点"与表达谱 | 网页为主 | 与 TCMSP 覆盖差异大，建议双库并集 |
| **ETCM** | 中医药整合数据库，含方剂与药材 | 网页 | 更新频率低于 TCMSP |
| **SymMap** | 症状-中药-成分-靶点映射 | 网页 | 适合"证候"研究 |
| **TCMID / TCMBank** | 成分与靶点补充 | 网页 | 靶点注释质量参差 |
| **BATMAN-TCM** | 中药成分靶点预测（score 阈值） | 网页，score ≥20 | 预测为主，需交叉 |
| **PubChem** | 化合物结构/CID/SMILES | PUG REST 可脚本化 | 中药成分名常查不到（缩写、超长 IUPAC），标 NA 不要伪造 |
| **ChEMBL** | 实测活性（IC50/Ki） | REST/网页 | 单成分机制研究的首选实测证据源 |

## 2. 靶点预测

| 资源 | 输入 | 阈值建议 | 说明 |
|---|---|---|---|
| **SwissTargetPrediction** | SMILES | probability ≥0.1 或 Top 15/100 | 单成分首选；多库交叉 |
| **PharmMapper** | 结构 | fit score 前列 | 反向药效团，适合无靶点注释成分 |
| **SuperPred / SEA** | SMILES | 概率阈值 | SEA 基于相似性，适合有类似物的成分 |
| **STITCH** | 化合物名 | score ≥0.4 | 含间接关联，噪声较大 |

> **纪律**：至少两个来源，并记录每个靶点的来源；单库预测的靶点集不应直接当"药物靶点全集"。

## 3. 疾病基因

| 资源 | 证据类型 | 使用建议 |
|---|---|---|
| **OMIM** | 遗传变异-表型（强） | 作为机制锚点，数量少 |
| **ClinVar / GWAS Catalog** | 遗传关联 | 同上 |
| **DisGeNET** | 审编关联（score） | score ≥0.1–0.2；注意版本 |
| **CTD** | 化学-基因-疾病互作，含直接证据 | 毒理学首选 |
| **Open Targets** | 整合评分 + 遗传/表达/文献分层 | GraphQL 可取，适合脚本化 |
| **GeneCards** | 整合关联（含文本挖掘） | **score 是相关性，不是因果**；对脚本 403 |
| **MalaCards** | 疾病-基因汇总 | 同上，仅作补充 |
| **GEO** | 表达差异（特定样本 vs 对照） | 是"表达变化"不是"疾病靶点"，须写明数据集与组织 |
| **TCGA / GEPIA2** | 肿瘤表达与生存 | 仅肿瘤；注意对照定义 |

> **分层呈现**是硬要求：遗传证据 / 审编关联 / 整合相关 / 表达变化，四类混为一谈会被直接质疑。

## 4. PPI

| 资源 | 说明 | 要点 |
|---|---|---|
| **STRING** | 功能关联（含文本挖掘、共表达、同源） | 物种 9606；`combined_score` 0.4 中 / 0.7 高；**不是物理结合** |
| **BioGRID / IntAct** | 实验验证的物理互作 | 覆盖窄但证据强 |
| **GeneMANIA** | 功能相似性网络 | 适合无物理互作的场景 |
| **HIPPIE** | 置信度整合 | 可作为交叉验证 |

**必写**：物种、边类型（functional / physical）、score 阈值、访问日期、是否含"额外互作蛋白"。

## 5. 通路与功能

| 资源 | 用途 | 注意 |
|---|---|---|
| **KEGG** | 通路 | 2024 起部分下载转订阅；脚本接口可能受限 |
| **Reactome** | 通路（人工审编） | 层级结构，注意父子条目重叠 |
| **WikiPathways** | 社区通路 | 覆盖较窄但更新快 |
| **GO** | BP/CC/MF | 条目极多，必须折叠 |
| **MSigDB** | 基因集集合（Hallmark 等） | 适合 GSEA；Hallmark 冗余低 |
| **g:Profiler** | 一次拿 GO/KEGG/REAC/WP，自带 FDR | 本平台在线默认后端 |
| **Metascape / DAVID / KOBAS** | 网页富集 | 结果可复现性弱于 API，需存快照 |

## 6. 结构与对接

| 资源 | 用途 | 要点 |
|---|---|---|
| **RCSB PDB** | 受体结构 | 优选有共晶配体、分辨率 ≤2.5 Å；记录 PDB ID 与链 |
| **AlphaFold DB** | 无实验结构时替代 | 预测结构， pocket 可能偏差；需声明 |
| **PDBbind** | 打分基准 | 用于校准，不用于本研究结论 |
| **AutoDock Vina** | 对接 | 打分是相对值；必须重对接验证 |
| **GNINA / DiffDock** | ML 打分/盲对接 | 前瞻性基准提升有限，仍需实验 |
| **PLIP / LigPlot+ / PyMOL** | 相互作用可视化 | 氢键几何：D-H···A <3.5 Å 且角 >120° |

## 7. 表达与临床

| 资源 | 用途 |
|---|---|
| **GTEx / HPA** | 组织表达（判断靶点是否在靶组织表达） |
| **cBioPortal** | 肿瘤突变/拷贝数/表达 |
| **GEO** | 公共表达谱（差异分析、验证 hub） |
| **单细胞图谱（HCA / Tabula）** | 定位靶点所在细胞类型 |

## 8. 毒理与安全性

| 资源 | 用途 |
|---|---|
| **ProTox 3.0** | 预测 LD50 与毒性终点 |
| **admetSAR / pkCSM** | ADMET 预测 |
| **DILIrank / LiverTox** | 药物性肝损伤证据 |
| **CTD** | 化学-基因-疾病-毒性关联 |
| **《中国药典》2025 版** | 毒性药材标注（大毒/有毒/小毒）、限量 |
| **《医疗用毒性药品管理办法》** | 28 种法定毒性药品（与药典标注是两套目录，不可混用） |

## 9. 文献

| 资源 | 用途 | 要点 |
|---|---|---|
| **PubMed / E-utilities** | 主检索 | 用 MeSH + 字段标签，保存检索式 |
| **Europe PMC** | 全文 + 预印本 | 多词主题必须加引号 + AND，否则按 OR 处理 |
| **CNKI / 万方** | 中文文献 | 学位论文里常有实测含量数据 |
| **Google Scholar** | 引文追踪 | 不适合做可复现检索 |

## 10. 一张"该用哪个"的决策表

| 你要做的事 | 首选 | 次选 |
|---|---|---|
| 中药成分初筛 | TCMSP | HERB / ETCM |
| 成分靶点预测 | SwissTargetPrediction | BATMAN-TCM / PharmMapper |
| 疾病基因（要因果） | OMIM + GWAS | DisGeNET / CTD |
| 疾病基因（要广度） | Open Targets | GeneCards（声明为相关性） |

| 安全性 | 药典 + CTD | ProTox 3.0 |
