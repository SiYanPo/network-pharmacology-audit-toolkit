# 剂量与暴露：把"体外有效"翻译成"体内能不能到"

## 1. 为什么这一步不可省

网络药理学给出的靶点，常配一句"某成分在 50 µM 抑制了该通路"。
但若该成分在人体内游离峰浓度只有 0.05 µM，**整条机制链在暴露层面就断了**。
这不是"讨论一下局限"能解决的问题——它是结论是否成立的问题。

**最小要求**：给出"体外浓度 / 体内游离 Cmax"的比值，并分级。

## 2. 换算链（每一环都可替换为实测值）

```
① 饮片日剂量 D (g/day)           ← 药典用量；必须写"饮片"而非"提取物"
② 成分含量 C (%)                 ← 实测 HPLC/UPLC；无实测则标注"估"
③ 提取率 E (%)                   ← 水煎 30–70%（默认 50）；醇提不同
④ 日摄入量 M = D×1000×C%×E%  (mg)
⑤ 单次剂量 = M / 分服次数
⑥ 血浆总 Cmax ≈ F × 单次剂量 / (Vd × 体重)   （µM）
⑦ 游离 Cmax = 总 Cmax × fu
⑧ 比值 R = 体外有效浓度 / 游离 Cmax
```

### 公式（µM）

```
Cmax(µM) = (F/100) × dose_mg × 1000 / (MW × Vd × BW)
```

其中 `MW` g/mol，`Vd` L/kg，`BW` kg。

### 默认参数（必须声明为假设值）

| 参数 | 默认 | 说明 |
|---|---|---|
| F（口服生物利用度） | 30% | 与 TCMSP 的 OB 不是同一概念（OB 是预测值） |
| Vd | 1.0 L/kg | 亲脂性成分可 >5；极性成分 <0.3 |
| fu（血浆游离分数） | 0.1 | 黄酮/皂苷结合率高，常 <0.05 |
| 提取率 | 50% | 水煎 |
| 体重 | 60 kg | — |

## 3. 分级（比值 = 体外 / 体内游离）

| 比值 | 分级 | 含义 | 写作要求 |
|---|---|---|---|
| ≤1 | **可达** | 体内游离浓度不低于体外有效浓度 | 可正常讨论机制 |
| 1–10 | **同量级** | 需考虑组织蓄积、主动转运 | 加"在组织蓄积条件下可能达到" |
| 10–100 | **超出** | 体外高 1–2 个数量级 | 机制结论必须降级；建议低浓度复做 |
| >100 | **不可达** | 该浓度体内不可能达到 | 该体外结果不能作为机制证据 |

## 4. 算例（演示数据，构造值）

黄芪 9 g/日，槲皮素含量 0.042%，提取率 50%，MW 302.24，F 30%，Vd 1.0，BW 60，fu 0.1，
体外 50 µM：

| 环节 | 值 |
|---|---|
| 日摄入 | 9×1000×0.00042×0.5 = **1.89 mg** |
| 单次（2 次/日） | 0.95 mg |
| 总 Cmax | 0.3×0.95×1000/(302.24×1×60) = **0.0156 µM** |
| 游离 Cmax | **0.0016 µM** |
| 比值 | 50 / 0.0016 = **31,983 倍 → 不可达** |

**结论**：以"槲皮素 50 µM 抑制某通路"解释黄芪的体内作用，在暴露层面不成立。
可接受的说法是："体外高浓度（50 µM）下观察到…，但该浓度远高于人用剂量下的游离暴露
（约 0.0016 µM），其临床相关性有待低浓度实验验证。"

> 注意：这不等于"黄芪无效"。可能是其他成分、其他浓度、其他机制（如肠菌代谢物、组织蓄积）。
> 但**这一条证据链**不能用。

## 5. 敏感性分析（必做）

三个参数各取区间，给比值的**范围**而非单点：

```
含量 ×0.5 – ×2
提取率 30% – 70%
fu 0.02 – 0.2
```

若比值区间跨越数量级（例如 8 – 900），结论只能写"在有利假设下可达"，不能写"体内可达"。

## 6. 反推：要多少饮片才够？

```
D_required = Cmax_need × MW × Vd × BW × 分服次数 / (F × 1000) / (C% × E%) / 1000
```

若 >30 g/日（超出常用范围），说明该浓度在人用剂量下不可达。

## 7. 未计算部分（必须写进局限）

- 首过代谢的部位差异（肠壁 vs 肝）；
- 肠菌代谢活化（很多苷类需水解后才吸收）；
- 肝肠循环导致的多峰；
- 组织分布（靶器官可能远高于/低于血浆）；
- 蛋白结合竞争与多成分相互作用；
- Cmax 为单次给药上限估计，非稳态谷/峰。

## 8. 什么时候可以跳过这一步

只有当研究**明确不做体内外推**时才可跳过，且必须写：
"本研究为计算层面的机制假设生成，不涉及暴露量评估。"
——但注意：审稿人仍可能问"这个浓度体内能达到吗"，所以最好还是给一个量级估计。
