# 盲法二次标注工具包（revision 阶段用）

给**未参与本项目**的标注者，20 分钟完成，用于把归因标签的"内部一致性检查"升级为"评分者间信度"。

| 文件 | 用途 | 给谁 |
|---|---|---|
| `coding_manual.md` | 操作手册：5 类定义、判断顺序、结果解读表 | 标注者 |
| `blind_sheet.csv` | 25 篇分层抽样，只含判断所需证据列，`rater_label` 留空 | 标注者 |
| `kappa.py` | 算混淆矩阵、percent agreement、Cohen's κ + bootstrap 95%CI | 作者 |
| `ground_truth.csv` | 作者标签（**标注者不得打开**） | 作者 |

抽样：25 篇，按五类分层（prov 7 / both 6 / none 5 / herb 4 / thr 3），随机种子 20261125，可复现。

已验证脚本可用：以模拟标注（80% 一致）测试，输出 `κ = 0.742, 95%CI [0.519, 0.938]`。
真实结果出来后，按 `coding_manual.md` 末尾的三种情形改写稿件对应段落——三种结果都已预留落点。
