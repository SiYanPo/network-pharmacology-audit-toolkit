# 研究设计模式与工作量分级

## 一、先选模式（A–F），再定流程

| 模式 | 适用情形 | 核心增量 | 最少需要的对照 |
|---|---|---|---|
| **A 单方-单病（标准型）** | 复方/单味药 + 一个疾病 | 成分-靶点-通路链条完整 | 零模型 + hub 稳健性 |
| **B 单成分-机制** | 一个已知活性成分 | 省去成分筛选；靶点预测多库交叉 | 剂量可达性（关键） |
| **C 药对/配伍** | 两味药或"君臣佐使"关系 | 共享靶点 + 各自独有靶点 + 协同增量 | 单药对照（必须） |
| **D 老药新用** | 已上市药的新适应症 | 药物靶点（DrugBank/ChEMBL）× 疾病基因 + 网络邻近性 | 已知适应症作阳性对照 |
| **E 网络毒理学/安全性** | 毒性终点明确 | 毒性成分谱 + 靶器官基因集 + 暴露链 | 阳性毒物对照 |
| **F 反向/组方优化** | 只有疾病基因，或要选药 | 覆盖度/精确率/互补性/最小覆盖组合 | 泛成分剔除后的敏感性分析 |

**判据**：如果研究问题里出现"为什么是这几味药"，用 C 或 F；出现"这个成分到底能不能到靶点"，用 B + 剂量链。

## 二、四档工作量（按可发表层级）

| 档 | 周期 | 数据源数 | 对照 | 对接 | 目标 |
|---|---|---|---|---|---|
| **Lite** | 1–2 周 | 2 | 仅 B 组零模型 | top 3 | 内部报告/预实验/毕业论文基础章 |
| **Standard** | 3–5 周 | ≥2（分层） | B + C 组 | top 5 + 重对接 | 主流 SCI（IF 3–6） |
| **Advanced** | 6–10 周 | ≥3 + 表达验证 | 四套零模型 + 敏感性分析 | top 5–8 + MD | IF 6–10 |
| **Publication+** | 10–16 周 | ≥3 + 自测数据 | 全部 + 外部数据集复现 | 多靶点 + 实验验证 | 高影响力/机制明确 |

> 关键不是"做更多分析"，而是**每一档都补齐该档的证据缺口**：
> Lite 缺对照 → 补 B 组；Standard 缺暴露 → 补剂量链；Advanced 缺外部复现 → 补 GEO/自测。

## 三、每档的最小可执行清单

### Lite（能自圆其说）
- [ ] 成分表（阈值写明）
- [ ] 靶点标准化（映射率 ≥80%）
- [ ] 交集 + 韦恩
- [ ] STRING PPI + hub（≥2 指标）
- [ ] 富集（BH + 背景声明）
- [ ] B 组零模型
- [ ] 局限性 4 条

### Standard（能过审）
Lite + 
- [ ] 给药途径一致性
- [ ] 泛成分标记 + 占比
- [ ] 度匹配零模型（C 组）
- [ ] 富集冗余折叠 + 三层分级
- [ ] 对接 + 重对接 RMSD
- [ ] 剂量可达性核算
- [ ] 26 条红线审计无 FAIL

### Advanced（能争好刊）
Standard +
- [ ] 四套零模型（含参照库）
- [ ] hub bootstrap（≥200 次）+ 节点丢弃
- [ ] 敏感性分析（阈值/背景/泛成分剔除各跑一次）
- [ ] 表达数据交叉（GEO 差异基因或 WGCNA 模块）
- [ ] 单细胞/空间定位（如可得）
- [ ] MD 验证（RMSD/RMSF/Rg/氢键/MM-GBSA）

### Publication+
Advanced +
- [ ] 外部数据集复现（独立队列/独立 GSE）
- [ ] 自测成分（LC-MS / 入血成分）
- [ ] 体外验证（至少 hub 中 2–3 个靶点）
- [ ] 体内或类器官验证
- [ ] 预注册分析计划或公开代码与中间数据

## 四、六种"常见设计缺陷"及其替代

| 缺陷 | 为什么会发生 | 替代设计 |
|---|---|---|
| 注射剂用 OB 筛成分 | 照抄模板 | 用制剂含量 + 入血成分；或明确"可成药性预筛" |
| 复方当单药相加 | 图省事 | 加"单药 vs 组合"的覆盖度与协同增量 |
| 只做 hub 不做通路 | 图好看 | hub 必须落到通路/细胞类型，否则只是拓扑练习 |
| 疾病靶点越多越好 | 以为覆盖广=可靠 | 分层 + 阈值；靶点集过大时改用反向设计（F） |
| 对接当验证 | 成本最低的"验证" | 对接作为 L2 候选筛选，验证靠 SPR/细胞 |
| 只报显著通路 | 选择性报告 | 完整表入附录 + 折叠前后计数 |

## 五、立项/标书的技术路线写法（六段式）

1. **临床/科学问题**：一句话（谁、什么病、缺什么证据）。
2. **假说**：成分群 → 关键靶点 → 通路 → 表型，写成一句可证伪的话。
3. **技术路线**：对应本平台 01–09 的阶段图（可直接引用 `01-workflow-detail.md` 的依赖图）。
4. **关键对照**：零模型、单药对照、阳性对照（对接/毒理）。
5. **可行性**：数据是否已具备、样本量、预实验基础。
6. **风险与预案**：交集不足怎么办、靶点无抗体怎么办、剂量不可达怎么办。

> 标书里最容易被扣分的是"只有技术没有对照"。把零模型与剂量链写进技术路线，评审会明显加分。

## 六、四种"换个思路"的选题方向（避免同质化）

| 方向 | 一句话 | 差异化点 |
|---|---|---|
| **暴露优先** | 先做入血成分，再做网络 | 从"数据库有什么"变成"体内真有什么" |
| **对照优先** | 以零模型/基准为核心卖点 | 方法学文章，天然抗质疑 |
| **配伍定量** | 用协同增量与覆盖互补解释"君臣佐使" | 回答复方特有科学问题 |
| **细胞定位** | hub 靶点落到具体细胞类型（单细胞/空间） | 从"哪些基因"到"哪些细胞" |
