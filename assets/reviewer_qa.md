# 审稿质疑速查卡（可打印）

> 左边是审稿人原话，中间是"他在担心什么"，右边是可以直接用的回应骨架。
> 原则：先判断意见对不对，再决定补数据 / 改措辞 / 有理有据地说明。

## A. 数据与筛选

| 审稿人可能说 | 真实担忧 | 回应骨架 |
|---|---|---|
| "成分来源不明" | 不可复现 | 库名+版本+日期+检索词；附表列每个成分的来源 |
| "为何用 OB≥30/DL≥0.18" | 阈值随意 | 说明为 TCMSP 体系通用阈值 + 承认预测性质 + 例外纳入清单 |
| "OB 阈值会漏掉有效成分" | 系统性漏检 | 承认；给例外纳入（实测含量/入血/文献）；讨论中列为局限 |
| "注射剂为何用口服参数筛" | 逻辑冲突 | 承认不适用；改以含量/入血成分为准，或声明为"可成药性预筛" |
| "疾病靶点几千个都相关吗" | 假阳性 | 按来源分层，给阈值与各层数量；说明 GeneCards 是相关性非因果 |
| "为何不用户外的药材" | 基原/炮制 | 补正名+拉丁名+炮制品；说明数据库只收生品的局限 |

## B. 网络与 hub

| 审稿人可能说 | 真实担忧 | 回应骨架 |
|---|---|---|
| "Degree 最大就是核心靶点？" | 度≠重要性 | 改称"拓扑稳健 hub"；给 8 指标共识 + bootstrap 入选频率 |
| "换个网络还是 hub 吗" | 稳健性 | 给入选频率表 + 节点丢弃 + 度匹配零模型 |
| "PPI 连接紧密有何对照" | 无零模型 | 给 A/B/C 三组零模型结果与经验 P |
| "STRING 的边是物理互作吗" | 证据类型 | 明确是 functional association；如要物理互作改用 BioGRID/IntAct |
| "MCODE 模块为什么这么大" | 算法退化 | 改用 Louvain；MCODE 需设规模上限 |

## C. 富集

| 审稿人可能说 | 真实担忧 | 回应骨架 |
|---|---|---|
| "富集条目太多" | 冗余 | 报折叠前后数量（54→12）+ 完整表入附录 |
| "Pathways in cancer 也算机制？" | 伞状通路 | 三层分级；伞状/感染类只作功能谱描述 |
| "背景基因集是什么" | 统计口径 | 明确 N 与 K 来源；无实测背景则标"探索性" |
| "为何说通路被激活" | 无方向 | 改为"显著富集"；方向需磷酸化/表达实验 |
| "P 值能说明作用强度吗" | 概念混淆 | 承认不能；补 fold enrichment 与命中数 |

## D. 对接与 MD

| 审稿人可能说 | 真实担忧 | 回应骨架 |
|---|---|---|
| "对接不能证明结合" | 证据等级 | 同意；改为"预测"；补 SPR/ITC 或说明为 L2 |
| "口袋怎么定的" | 可复现 | 共晶配体中心/残基/盲对接 + 盒子尺寸与中心坐标 |
| "重对接验证了吗" | 协议可靠性 | 给 RMSD；>2 Å 的靶点结果撤回或标探索性 |
| "为何只对接 5 个成分" | 选择性报告 | 说明依据（丰度/前序 top/文献）；承认覆盖不全 |
| "MM-GBSA 数值与文献差很多" | 模型简化 | 说明单轨迹+通用 GB，仅作同靶点相对排序 |

## E. 暴露与剂量

| 审稿人可能说 | 真实担忧 | 回应骨架 |
|---|---|---|
| "体外浓度体内能达到吗" | 暴露不可达 | 给剂量链与比值；>10 倍则机制结论降级 |
| "剂量依据是什么" | 可外推性 | 药典用量 + 体表面积换算 + 文献 |
| "复方等于单药相加吗" | 配伍 | 讨论溶出/代谢/转化；给协同增量或说明未做 |

## F. 写作与结论

| 审稿人可能说 | 真实担忧 | 回应骨架 |
|---|---|---|
| "结论过度" | 越级表述 | 逐句改 L0–L4；摘要加"computationally derived" |
| "创新性不足" | 同质化 | 指出差异化点（暴露优先/对照优先/配伍定量/细胞定位） |
| "缺少实验验证" | 证据链 | 若无法补，全文降级 + 明确列为局限 + 给验证方案 |
| "参考文献陈旧" | 时效 | 补近 3 年文献 ≥30%，尤其是方法学文献 |

## 三条通用策略

1. **能补数据的补数据**（成本最低的往往是补零模型与剂量链，不需要实验室）。
2. **补不了的改措辞**（把"证明"改"提示"，往往能救回一篇稿子）。
3. **不同意的要有依据**（引方法学文献，而不是"我们认为"）。
