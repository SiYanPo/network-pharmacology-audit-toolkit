# 论文提纲与图件清单

## 标题公式

`[受试物] 通过 [通路/靶点] 干预 [疾病] 的机制研究：基于网络药理学与 [验证手段]`

> 不要用"基于网络药理学探讨…"开头——这类标题已被过度使用，且暗示"只有计算"。
> 若确有验证，把验证手段写进标题。

## 结构（目标 3500–5000 字，6 图 2 表）

### Abstract（250 字）
背景 1 句 → 方法 2 句 → 结果 3 个数字 → 结论 1 句（带等级）

### 1 Introduction（600 字，3 段）
- 段 1：疾病负担与现有治疗缺口
- 段 2：受试物的临床基础与已知成分/机制（引 ≥5 篇）
- 段 3：本研究要回答的具体问题 + 创新点（**不用** "首次"）

### 2 Materials and methods（900 字）
2.1 数据源与检索（表 1）
2.2 成分筛选（阈值 + 途径一致性 + 例外纳入）
2.3 靶点标准化（词典 + 映射率 + 非人类剔除）
2.4 疾病靶点（分层 + 阈值）
2.5 PPI 与拓扑（版本 + 阈值 + 指标 + 稳健性）
2.6 富集（方法 + 背景 + 校正 + 折叠）
2.7 零模型（类型 + 次数 + 公式）
2.8 分子对接（受体 + 口袋 + 参数 + 重对接）
2.9 剂量核算（参数 + 假设）
2.10 统计与软件版本

### 3 Results（1500 字）
3.1 成分与靶点（图 1 成分-靶点网络）
3.2 交集（图 2 韦恩 + 表 1 靶点清单节选）
3.3 PPI 与 hub（图 3 网络 + 图 4 hub 条形/雷达）
3.4 零模型（图 S1 或正文小图）
3.5 富集（图 5 气泡 + 桑基）
3.6 对接（图 6 构象 + 相互作用）
3.7（可选）剂量可达性（图 S2）

### 4 Discussion（1200 字，4 段）
- 段 1：核心发现复述 + 与文献一致处
- 段 2：**不一致处及解释**（审稿人最看重）
- 段 3：生物学合理性（组织表达、细胞类型、剂量）
- 段 4：局限与展望（≥4 条）

### 5 Conclusion（150 字）
一句结论 + 等级 + 下一步
