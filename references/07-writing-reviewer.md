# 论文写作与审稿应答

## 1. 论文骨架（IMRaD 改造版）

| 章节 | 必须回答的问题 | 常见缺陷 |
|---|---|---|
| Introduction | 该方/该病为什么值得研究？已知机制缺哪一块？ | 大段抄"网络药理学是系统生物学…" |
| Methods·数据 | 每个数据库的名字 + 版本 + 访问日期 + 检索词 | "数据来自公共数据库" |
| Methods·筛选 | OB/DL/HL 阈值 + 依据 + 给药途径 | 阈值不写或与途径矛盾 |
| Methods·网络 | STRING 版本/物种/阈值/边类型 | 只说"构建 PPI 网络" |
| Methods·统计 | 检验方法、背景、校正、零模型次数、软件版本 | 无背景、无校正、无零模型 |
| Results | 每段一个可证伪的陈述 + 数字 | "如图所示，大量靶点被富集" |
| Discussion | 与文献机制对照；**不一致的地方怎么解释** | 只讲支持自己结论的文献 |
| Limitations | 数据库偏倚、阈值局限、无实验、暴露不可达 | 写"样本量小"这种通用套话 |

## 2. 图件清单（按投稿要求排序）

1. **成分-靶点网络**（药材/成分/靶点三层，节点大小=度，颜色=类别）
2. **韦恩图**（药靶 ∩ 病靶，标注各集合规模）
3. **PPI 网络**（标注 STRING 阈值；hub 用颜色区分）
4. **hub 条形图/雷达图**（至少 3 个拓扑指标）
5. **GO 三支 + KEGG 气泡图**（横轴 rich factor，点大小=基因数，颜色=q）
6. **成分-靶点-通路 桑基图或网络图**
7. **分子对接构象 + 相互作用 2D 图**（标注残基、氢键距离）
8. **（可选）剂量可达性图**：饮片量-成分量-游离浓度-体外浓度对比
9. **（可选）零模型分布图**：观察值 vs 零分布直方图 ← 加分项，审稿人很吃这套

> 图注必须自含：物种、阈值、n、统计方法。不能出现"详见图注"却没写。

## 3. 审稿 20 问逐条应答

> 用法：先判断这条意见"对不对"，再决定"补数据 / 改措辞 / 争辩"。客套不超过一句。

**Q1 成分从哪来？阈值为什么这么设？**
答：写明库名+版本+日期+阈值+依据。若给药途径非口服，承认 OB 不适用，改为含量/入血成分，
或在局限性中明确"本研究为成分可成药性预筛，非暴露筛选"。

**Q2 为什么用 OB≥30/DL≥0.18？会漏掉有效成分吗？**
答：会。OB/DL 是预测值，系统性漏掉苷类、多糖、挥发油。已设"例外纳入"清单（附实测含量或文献依据），
并在讨论中说明该清单是"部分"而非全集。

**Q3 疾病靶点几千个，都相关吗？**
答：不能都算。按来源分层：OMIM/GWAS（遗传）、DisGeNET/CTD（审编）、GeneCards（整合相关）、
GEO（特定样本表达）。给阈值与各层数量。

**Q4 Degree 最大就是核心靶点？**
答：不是。度只反映连接数。我们改用 8 项指标秩均值 + 200 次 bootstrap 入选频率（附表），
并以度匹配零模型检验（P=…）。入选频率 <0.60 的节点只称"度排序前列节点"。

**Q5 网络"连接紧密"有对照吗？**
答：有。四套零模型：全基因组随机、疾病集内随机、度匹配随机、（可选）参照成分库。
B 组 P=…，C 组 P=…。若 C 组不显著，我们已把结论降级为"靶点集合"而非"功能模块"。

**Q6 富集为什么这么多通路？**
答：因为冗余。已按基因集 Jaccard≥0.5 折叠（54→12），并报告折叠前后数量。
完整表在附录。

**Q7 "Pathways in cancer" 能当机制吗？**
答：不能。已分为三层：机制明确 / 伞状泛化 / 背景性（感染类）。伞状与感染类仅作功能谱描述。

**Q8 为什么没有激活/抑制的结论？**
答：因为 GO/KEGG 输入是无方向基因集。方向性结论需磷酸化或表达实验，我们在局限性中说明。

**Q9 对接能证明结合吗？**
答：不能。对接是 L2 结构预测。我们报告了口袋来源、质子化处理、重对接 RMSD（≤2 Å 为通过），
并按 −5/−7/−9 分级；要主张结合需 SPR/ITC/MST。

**Q10 为什么只对接了 5 个成分？**
答：说明依据（丰度前 5 / 前序网络 top / 有文献活性证据）。若为省时，如实写"选取代表性成分"，
并承认覆盖不全。

**Q11 有实验验证吗？**
答：若有，注明验证了哪几个靶点、剂量、模型；若无，全文措辞停在"提示/支持"，
并在摘要中明确"computationally derived"。

**Q12 剂量能到吗？**
答：给核算链：饮片 g → 含量% → 提取率 → 日摄入 mg → 游离 Cmax µM → 与体外浓度比值。
比值 >10 时说明该体外浓度体内不可达，机制结论降级。

**Q13 复方为什么等于单药相加？**
答：不等于。我们在讨论中说明溶出、代谢酶抑制、配伍对毒性/活性成分转化的可能影响；
若未做配伍实验，明确这是局限。

**Q14 炮制考虑了吗？**
答：写明生品/制品、基原、药用部位。生首乌与制首乌、生附子与制附子是不同受试物。

**Q15 物种与组织语境？**
答：STRING 物种 9606；靶点在靶组织的表达用 GTEx/HPA 核对（附表）。

**Q16 数据库版本？**
答：逐条列出（TCMSP 2026-11-19 访问；STRING v12.0；KEGG 2026-11-19 访问…）。

**Q17 结果能复现吗？**
答：提供 run_manifest（输入哈希、参数、种子、脚本版本）+ 原始检索结果 + 完整中间表。

**Q18 为什么选这个疾病模型？**
答：说明与临床表型的对应关系、模型局限性（种属差异、诱导方式）。

**Q19 结论是否过度？**
答：摘要与结论逐句核对措辞等级（L1 只用"提示/支持"）。这是最容易被抓的一条。

**Q20 利益冲突 / 数据可用性？**
答：数据可用性声明指向仓库或附录；说明是否有临床样本与伦理批号。

## 4. 摘要模板（含措辞分级）

> **背景**：X 方用于 Y 病，机制未明。
> **方法**：基于 TCMSP（OB≥30%，DL≥0.18）筛选 n 个成分，预测 m 个靶点；与疾病靶点
> （OMIM/DisGeNET/GeneCards，分层）取交集得 k 个共同靶点；STRING（0.4）构建 PPI，
> 以 8 项指标秩均值 + bootstrap 确定候选 hub；GO/KEGG 富集（BH 校正，q<0.05）；
> 分子对接（Vina，含重对接验证）；1000 次零模型评估网络紧密性。
> **结果**：k 个共同靶点；hub 为 A/B/C（入选频率 0.98/0.94/0.71）；
> 富集于 P1/P2（q=…，命中 n/N）；对接显示 … 结合能 −8.4 kcal/mol（L2）。
> **结论**：**提示** X 方可能通过 P1/P2 通路作用于 A/B/C；该结论为计算预测（L1–L2），
> 尚需体外/体内验证。**未**评估剂量-暴露关系，不作为临床依据。

## 5. 五句"最容易被拒"的话（附改写）

| 原句 | 问题 | 改写 |
|---|---|---|
| "网络药理学**证明**了…" | 越级 | "网络药理学**提示**…" |
| "分子对接**验证**了结合" | 预测当实测 | "分子对接**预测**二者可结合" |
| "AKT1 是**核心靶点**" | 度≠重要性 | "AKT1 为**拓扑稳健的 hub 节点**（入选频率 0.98）" |
| "该通路被**激活**" | 无方向信息 | "该通路**显著富集**（q=…，命中 8/14）" |
| "为临床应用**提供依据**" | 越界 | "为后续实验研究**提供候选靶点**" |
