# 中药与民族药的特殊性

> 通用网络药理学流程直接套到中药上，会在四个地方系统性出错：**基原、炮制、配伍、剂量单位**。
> 本章只写"必须改什么"，不重复通用流程。

## 1. 基原：错一步，后面全错

| 易混品种 | 后果 |
|---|---|
| 关木通（马兜铃科）≠ 川木通（毛茛科） | 前者含马兜铃酸，肾毒；后者安全 |
| 土三七（菊三七）≠ 三七（五加科） | 前者含吡咯里西啶，肝窦阻塞综合征 |
| 白首乌（萝藦科）≠ 何首乌（蓼科） | 成分谱完全不同 |
| 防己（粉防己）≠ 广防己（含马兜铃酸） | 已停用品种混用 |

**要求**：
- 写"药材正名 + 拉丁学名（含命名人）+ 药用部位 + 炮制品"。
- 拉丁名以《中国药典》2025 版为准；地方习用品须注明标准来源。
- 网络药理学不能做基原鉴定结论——这需要性状/显微/理化/DNA 条形码。

## 2. 炮制：生品与制品是两个受试物

| 药对 | 成分变化 | 对网络的影响 |
|---|---|---|
| 生附子 → 制附子 | 双酯型生物碱（乌头碱等）水解为单酯型/醇胺型，毒性降 10–100 倍 | 靶点谱显著改变；不区分炮制的方法学不成立 |
| 生首乌 → 制首乌 | 蒽醌苷减少、游离蒽醌增加；结合型转游离型 | 肝毒性与药效方向都可能反转 |
| 生半夏 → 制半夏 | 草酸钙针晶破坏、凝集素失活 | 毒性靶点消失 |
| 生黄芪 → 蜜炙黄芪 | 多糖与皂苷比例变化 | 免疫相关靶点权重变化 |

**要求**：成分检索时用**对应炮制品**的名称（TCMSP 多数只收生品，须在局限中说明）。

## 3. 配伍：复方 ≠ 单药相加

三个必须讨论的层面：

1. **溶出**：共煎时 pH、表面活性（皂苷）、络合（鞣质-生物碱）改变溶出率。
2. **代谢**：一味药抑制 CYP3A4 可抬高另一味药的暴露（如甘草、黄连）。
3. **转化**：配伍可促进毒性成分转化（附子配甘草：甘草酸促进双酯型生物碱水解）。

**可量化的做法**（本平台 `np_optimize.py`）：
- 每味药的 coverage / precision / marginal；
- 组合的**协同增量** = 组合覆盖 − 各药单独覆盖之并。
- 协同增量 = 0 → 只能从剂量/代谢/通路上下游解释，**不能**称"多靶点协同"。

## 4. 剂量单位：克是饮片，不是提取物

| 混淆 | 差异 |
|---|---|
| 饮片 9 g vs 提取物 9 g | 成分量差 10–100 倍 |
| 古方"一两" | 东汉≈13.8 g，宋金元≈41.3 g，明清≈37.3 g —— 不能一律按 3 g |
| 鲜品 vs 干品 | 含水量差 3–5 倍 |

**要求**：剂量链的起点必须是"饮片 g/日"，并写明是汤剂、散剂还是提取物。

## 5. 民族药额外三关

| 关口 | 问题 | 处理 |
|---|---|---|
| 理论映射 | 藏医"三因"、蒙医"三根"、维医"四大物质"不能直接等同西医概念 | 映射须给文献依据；不写"即中医的××" |
| 矿物药 | 佐太、朱砂、雄黄含汞/砷/硫 | 必须单列安全性章节；做形态分析而非只测总量 |
| 保护物种 | 麝香、熊胆、穿山甲、羚羊角 | 核实合法性、人工替代与专用标识；名录会调整 |

## 6. Q-marker（质量标志物）的正确用法

刘昌孝院士提出的五要素：**有效性、特有性、可测性、传递性、处方配伍**。

网络药理学能贡献的是"有效性"这一维（成分→靶点→疾病），**不能**单独定 Q-marker。

| 步骤 | 数据要求 |
|---|---|
| 有效性 | 网络药理学 + 体外活性（至少一类） |
| 特有性 | 该成分在近缘种/混淆品中是否存在（化学分类学） |
| 可测性 | 有无对照品、HPLC/UPLC 方法可行性 |
| 传递性 | 从药材→饮片→汤剂→入血的传递率 |
| 配伍 | 在全方中的地位（君臣佐使 / 含量占比） |

**常见错误**：把网络药理学 top 成分直接当 Q-marker，不做可测性与特有性核查。

## 7. 入血成分：把"数据库有什么"变成"体内真有什么"

优先级（从高到低）：

1. **自测血清药物化学**（给药后取血，UPLC-Q-TOF 鉴定原型与代谢物）
2. **文献报道的入血成分**
3. **实测含量高的成分**（HPLC）
4. **TCMSP 预测成分**（OB/DL）

> 只有 1–3 级能支撑"该成分在体内存在"的表述；4 级只能写"预测可吸收"。

## 8. 中药研究的"最小可信集"

一份能过审的中药网络药理学研究，至少要有：

- [ ] 正名 + 拉丁学名 + 药用部位 + 炮制
- [ ] 饮片日剂量（g）+ 来源（药典/临床处方）
- [ ] 成分来源（库名+版本）与筛选阈值
- [ ] 至少一层实测（含量或入血成分）
- [ ] 疾病靶点分层
- [ ] 零模型 + hub 稳健性
- [ ] 富集背景 + 折叠
- [ ] 剂量可达性
- [ ] 炮制/配伍/基原对结果的潜在影响（讨论）
- [ ] 局限性与临床边界声明
